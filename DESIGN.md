DiveAtlas visual design principles

1. DiveAtlas is a cartographic/data product, not a SaaS landing page.

2. The map and geographic data should provide the visual richness.
   UI chrome should remain quiet and utilitarian.

3. Avoid generic AI-generated web aesthetics:
   - oversized bold hero typography
   - excessive rounded cards
   - pill-shaped buttons
   - card-inside-card layouts
   - excessive shadows/glows
   - centered-everything layouts
   - decorative gradients
   - excessive use of brand color
   - large empty hero spacing

4. Prefer:
   - compact typography
   - left alignment
   - subtle 1px dividers
   - restrained 4–10px radii
   - flat surfaces
   - whitespace instead of containers
   - native map/data colors
   - strong information hierarchy
   - compact controls

5. Radius hierarchy:
   modal: 12px
   image: 6px
   control/button: 6px
   small control: 4px

   Never create nested large-radius containers.

6. Typography:
   Main title: 28–32px / 600–650
   Section title: 16–18px / 600
   Body: 14–15px / 400
   Labels: 12–13px / 500

   Avoid font-weight 800 unless the product logo requires it.

7. Buttons:
   Avoid pill buttons.
   Normal control height: 36–40px.
   Border radius: 5–7px.

8. Prefer borders/dividers over cards.

9. Use shadows only when establishing real elevation:
   overlay/modal is allowed;
   ordinary content sections should not have shadows.

10. If removing a container does not hurt comprehension,
    remove the container.
